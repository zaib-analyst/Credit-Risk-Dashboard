# Credit Risk Analysis Dashboard

An interactive two-page Excel dashboard analyzing credit risk 
across 5,000 bank customers.

## Project Overview
| Field | Detail |
|---|---|
| Sector | Finance & Banking |
| Dataset | Kaggle Credit Risk Dataset |
| Records | 5,000 customers, 22 columns |
| Tool | Microsoft Excel + VBA |
| Pages | 2 — Risk Summary + Customer Profile |

## Dashboard Features
- 2-page VBA navigation with active/inactive button toggle
- 12 KPI cards across both pages
- 10 interactive charts
- 10 pivot tables
- 3 slicers connected across both pages
- Dark professional theme

## Page 1 — Risk Summary
- Total Customers, High Risk %, Total Debt, Avg Credit Score
- Credit Risk Distribution donut chart
